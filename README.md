# Smit Premium Dry Fruits

Premium Dry Fruits online store for Adaai, New Panvel.

## Features

- Product listing and search
- Add to Bucket / Cart
- Quantity selection
- Delivery charge calculation
- Free delivery above ₹1,500
- QR payment demo flow
- Invoice and order ID demo
- Customer delivery address and live-location option
- Admin panel UI
- Product, stock and discount management UI
- Daily sales report integration placeholder

## GitHub Pages Setup

1. Upload `index.html` in the repository root folder.
2. Upload the `assets` folder in the same repository.
3. Go to GitHub repository Settings.
4. Open Pages.
5. Under Build and deployment, select:
 - Branch: `main`
 - Folder: `/ (root)`
6. Click Save.

Your website link will be similar to:

https://your-github-username.github.io/repository-name/

## Important

This is currently a frontend/static website.

For real features such as secure admin login, real UPI payment verification,
invoice PDF generation, live order tracking, stock management, automatic Excel
reports, email reports, product image uploads and database storage, you need:

- Backend API
- Database
- Secure authentication
- Payment gateway
- Email/SMTP service

Never upload real passwords, API keys, payment keys or email passwords to GitHub.
